# Parking On — 제1주차장 A/B/C/D 구역 지도 v3

## 실행
```powershell
npm.cmd install
npm.cmd run dev
```

제1주차장은 A/B/C/D 네 구역으로 구성됩니다. 실제 예약과 감지는 A구역 A1~A3 세 면만 지원하며 B/C/D는 미운영 표시입니다. 지도 드래그/확대, A구역 확대, 예약 및 취소, localStorage 데모 저장을 지원합니다. Flask API 모드는 기존 구현을 유지합니다.


## v4 구역 확대
- 지도에서 A/B/C/D 구역을 누르면 해당 구역 중심으로 확대됩니다.
- 지도 아래 A/B/C/D 버튼으로 구역을 빠르게 전환합니다.
- 우측 하단 전체 지도 버튼 또는 상세 패널의 전체 보기를 누르면 복귀합니다.
- A구역 A1~A3만 예약 가능합니다. B/C/D는 탐색만 지원합니다.
